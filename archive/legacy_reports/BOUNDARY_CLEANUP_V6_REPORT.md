# v6 几何锁定边界清洁报告

## 结论

v6 保留 v5 的生成先验盲去噪、原有增强与后处理链，在其输出之后新增一个几何锁定的边界清洁阶段。最终 16 位结果为：

```text
results_sota/03_boundary_cleanup/QUALITY_boundary_clean_16bit.tif
```

给定参考图只用于定义“暗背景安静、层片边界干净、中央高亮完整”的外观目标。它没有参与配准、训练监督、几何拟合或像素回写。所有边界掩膜均由原始 16 位图像的亚像素端点坐标生成，最终像素仅从 v5 增强结果计算得到。

## 新增方法

1. **原始坐标端点包络**：分别拟合左右层纹的上、下端点曲线，构造边界、外部与内部三个软掩膜。
2. **轴向细降噪**：采用 `σ=(2.00, 0.18)` 的各向异性核，主要沿层片长度方向降噪，避免跨越横向厚度边缘。
3. **边界外清洁**：仅在端点包络外使用 `σ=1.15` 的细平滑，并削减 `G₂.₂-G₇` 的正向雾状残差。
4. **端点核心保护**：每条层纹的原始上下端点邻域禁止修改；全局单像素变化还受 `0.8×MAD` 上限约束。
5. **自动强度选择**：扫描八组参数，同时检查 FWHM、端点、长度、边缘锐度、局部对比度、边界梯度和 SSIM。

## 本图实测结果

相对于完整 v5 增强输出：

| 指标 | v6 结果 |
|---|---:|
| 边界外高频噪声降低 | 4.26% |
| 边界外正向雾状光晕降低 | 10.99% |
| 层片内部轴向噪声降低 | 10.12% |
| 横向边缘锐度保持率 | 100.01% |
| 局部对比度保持率 | 100.00% |
| 边界梯度保持率 | 95.70% |
| 相对 v5 的 SSIM | 0.998538 |
| 相对原图最大中位 FWHM 变化 | 1.19% |

独立长度审计检测到 100 条层纹，98 条自动通过，2 条因原始端点本身置信度较低而进入人工复核。可靠层纹端点偏移 P95 为 0.248 像素，长度变化 P95 为 0.402 像素，最大长度变化为 0.499 像素，均通过设定保护阈值。

## 复现

```bash
docker compose run --rm ct-sota
```

也可单独运行边界清洁阶段：

```bash
python app/boundary_cleanup.py \
  --source input/source_16bit.tif \
  --input results_sota/02_geometry_quality/QUALITY_boundary_preserved_16bit.tif \
  --reference-style input/reference_style.jpg \
  --outdir results_sota/03_boundary_cleanup
```

`--reference-style` 仅记录参考图的尺寸和角色，省略它不会改变算法。测量前应检查 `boundary_cleanup_metrics.json`、端点叠加图和 `04_length_audit/length_qa.json`。

## 限制

当前数据仍是单图内部验证，没有配对干净真值、重复扫描或跨设备测试。像素坐标一致性不等于毫米或微米级计量认证；物理测量仍需要像素标定、可溯源标准件、系统 PSF/MTF 与重复性实验。
