# v18 规整边界与结构细节兼容增强报告

## 1. 设计目标

v11通过有限宽解析片层和三轮FWHM闭环得到非常规整的边界，但会重建整条层纹，可能覆盖真实局部起伏、缺口和轴向细节。v17把结构载体放入扩散生成过程，结构相关性更高，但继续增强边缘时容易使少量临界层纹越过宽度或双证据门槛。

v18采用保守的分层策略：保留v17生成式去噪结果，只把v11的“有限宽几何定位和逐层闭环验收”引入后处理，不把v11解析片层像素写回图像。输出仍包含生成像素，因此继续标记为`MEASUREMENT_CANDIDATE`。

## 2. 完整流程

```text
原始16位图 + v16结构载体
        │
        ├─测量100条层纹、98个夹层、中心线、端点、FWHM
        └─逐行测量并稳健平滑局部宽度轨迹（仅用于约束审计）

v17结构条件扩散结果
        │
        ├─有限宽边界场：横向零相位对称细节增强
        ├─端点场：纵向零相位对称细节增强
        └─夹层中心：远离FWHM边界的受限残差收缩
                │
                ├─逐条层纹/夹层重新测量
                ├─发生退化的局部结构逐像素回退到v17
                └─全部门槛通过后输出v18
```

没有执行缩放、配准、空间形变、坐标重采样或整条层纹解析重绘。目标ROI之外与v17逐像素一致。

## 3. 约束场后处理

边界增强仅使用v17本身的零相位横向高频残差：

\[
I_b=I_{17}+\lambda_b B\left(I_{17}-G_{0,\sigma_x}*I_{17}\right),
\]

端点采用对应的纵向残差。`B`和端点场来自v16载体测得的中心线、有限宽FWHM和端点。夹层只在距离层纹边界超过约1.6像素的区域收缩各向同性高频残差，避免改变半高宽使用的边界邻域。全部变化再受载体MAD噪声估计的幅度上限控制。

正式候选网格同时搜索边界增益、端点增益和夹层去噪强度。本图最终选择：

- 边界增益：`0.06`；
- 端点增益：`0.025`；
- 夹层残差收缩：`0.08`；
- 单像素最大变化：`0.0041896`（归一化强度）；
- 逐行宽度变化保留系数：`0.35`，用于导出审计约束。

## 4. 选择性逐层回退

全图处理后，系统把每条层纹和夹层与未修改的v17重新比较。只要出现以下任一情况，就恢复该层纹及相邻夹层的v17像素：

- 层纹宽度误差超过基线容差；
- 长度或端点误差超过容差；
- 原图/载体双证据由通过变为失败；
- 相邻夹层宽度、长度或双证据发生退化。

本图有74条层纹保留增强，26条临界层纹自动回退。该策略避免为了整体视觉锐度牺牲少数薄弱结构。

## 6. 运行和输出

```bash
docker compose run --rm ct-v18-constrained-detail-fusion
```

或：

```bash
python app/constrained_detail_fusion.py \
  --source input/source_16bit.tif \
  --carrier results_generative_shape_v16_measurement_quality/FINAL_MEASUREMENT_v16_quality_enhanced_2200x1600_16bit.tif \
  --generated results_generative_shape_v17_structure_conditioned_diffusion/MEASUREMENT_CANDIDATE_v17_structure_conditioned_16bit.tif \
  --outdir results_generative_shape_v18_clean_edges_detail_preserved
```

主要输出包括最终16位TIFF、预览、四联比较图、处理权重审计图、层纹/夹层对比CSV、逐行宽度约束CSV和JSON指标清单。

## 7. 使用边界

v18兼顾的是“可审计的增量视觉清理”和“相对结构载体的测量一致性”，不是计量认证。最终图仍包含v17生成像素；独立物理测量应优先读取导出的约束CSV或非生成式v16载体，并通过同设备重复扫描、标准样件、像素尺寸以及PSF/MTF完成标定。
