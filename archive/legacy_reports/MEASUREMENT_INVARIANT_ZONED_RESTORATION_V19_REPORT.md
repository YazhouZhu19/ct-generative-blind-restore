# v19 测量不变量分区复原技术报告

> 报告状态：本文依据当前 `app/structure_anchored_multiregion_denoise.py` 实现、完整候选搜索和16位写回审计编写。第2节数字来自同一CPU容器中的2200×1600全分辨率运行。本文不将单图结果表述为通用最优或SOTA结论。

## 1. 技术摘要

v19在不削弱v17生成式复原和v18规整边界增强的前提下，把后续去噪改造成“测量不变量约束下的分区复原”。它不再调用新的生成模型，也不重绘层纹，而是以v18为像素基线，在四类区域独立估计并收缩高频残差：完整层纹/夹层束、中央实体、端点外侧雾状区和低结构背景。

完整搜索选择的区域强度为`stack=0.02`、`central=0.50`、`fog=0.60`、`flat=0.50`。相对v18输入，中央实体、端点外侧雾状区和低结构背景的高频残差分别下降约9.51%、14.26%和11.99%；层纹与夹层的下降刻意限制在0.0561%和0.1097%，以避免为追求视觉平滑而改变可测结构。结果同时得到0.315009%的层纹宽度误差P95、0.209611%的夹层宽度误差P95、0.004734 px的端点偏差P95、99/96条层纹/夹层双证据通过数，以及相对v18为0.999892的SSIM。9/100条临界层纹被精确回退，写回TIFF后的第二次发布审计全部通过。

v19的核心不是更强的全图滤波，而是把“可以更强去噪的区域”和“必须保持测量响应的区域”分开。端点与轮廓敏感像素在每个候选中恢复为完全相同坐标的v18像素；层纹束只沿轴向滤波，不发生横向混合；每个候选在16位量化后重新测量，发生退化的层纹及邻近夹层自动回退到v18。最终输出仍包含v17生成像素，因此继续标记为`MEASUREMENT_CANDIDATE`，不能等同于经标定的计量真值。

## 2. 容器验证结果：低结构区获得明显降噪，宽度仍受严格门槛约束

### 2.1 选定参数

| 区域 | 选定强度 | 处理方向与目的 |
|---|---:|---|
| 层纹/夹层完整束（stack） | 0.02 | 仅沿层纹长轴抑制随机起伏，不跨越层纹宽度混合 |
| 中央实体（central） | 0.50 | 各向同性局部Wiener残差收缩，清理实体内部颗粒噪声 |
| 端点外侧雾状区（fog） | 0.60 | 在端点硬锚之外抑制雾状高频残差和正向光晕 |
| 低结构背景（flat） | 0.50 | 在低梯度、低保护权重区域进行较强背景清理 |

### 2.2 量化指标

下表中的“噪声下降”均以未修改的v18图像为基线；结构误差来自原图、v16结构载体和输出图的同坐标约束审计；SSIM以v18为基线。百分数均为相对量。

| 低结构背景高频残差下降 | 11.99% |
| 层纹轴向残差下降 | 0.0561% |
| 夹层高频残差下降 | 0.1097% |

这些结果说明，视觉上最需要处理的中央、雾状和背景区域可以获得显著高于层纹本体的去噪幅度。层纹与夹层的改善较小是主动的安全取舍，而不是滤波失效：任何更强候选仍必须通过FWHM、端点、拓扑、细节相关性和逐行宽度门槛。

上述数字均来自本次完整搜索生成的`structure_anchored_multiregion_v19_metrics.json`及其`post_write_uint16_release_audit`。高频残差下降是固定算子下的代理指标，不等同于具有无噪真值的绝对去噪率。

## 3. 范围、输入和指标定义

### 3.1 三类输入各司其职

- **原始16位图像**：提供原始同坐标观测，用于层纹与夹层约束测量。
- **v16非生成式结构载体**：为中心线、层距、端点和有限宽测量提供稳健引导；它仍是几何审计的权威载体。
- **v18增强图像**：作为v19的像素基线，已经包含v17结构条件生成残差以及v18有限宽边界/端点清理。

v19只在v18像素上执行增量后处理。它不替换v17或v18，也不把v16直接绘制回结果。

### 3.2 本报告所用指标

- **高频残差RMS**：图像与零相位高斯低通结果之差在指定掩膜内的均方根，用于比较v19相对v18的降噪比例。
- **层纹宽度误差P95**：逐层输出FWHM相对于结构约束的相对误差第95百分位。
- **夹层宽度误差P95**：相邻层纹间有限宽间隔相对于约束的相对误差第95百分位。
- **端点偏差P95**：约束端点与输出端点的绝对偏差第95百分位，单位为像素。
- **双证据通过数**：同时满足原图证据和结构载体证据的层纹或夹层数量。
- **SSIM**：v19与v18在目标ROI内的结构相似度；它衡量整体非回归，但不能代替逐层几何审计。

## 4. 完整流程：先保留生成与增强，再进行分区去噪和发布审计

```text
原始16位图 ───────────────┐
                          ├─ 同坐标测量层纹、夹层、中心线、端点与FWHM
v16非生成式结构载体 ─────┘
                          │
                          ├─ 构造结构图、端点包络和测量算子支持域
                          │
v17结构条件生成结果
        │
        └─ v18有限宽边界清理与逐层回退
                          │
                          ▼
                    v18像素基线
                          │
        ┌─────────────────┼──────────────────┐
        │                 │                  │
  层纹/夹层轴向滤波   中央实体滤波    雾状区与低结构背景滤波
        └─────────────────┼──────────────────┘
                          │
             恢复端点/敏感轮廓硬锚像素
                          │
             量化为uint16后逐层重新测量
                          │
        宽度、端点或双证据退化的局部结构回退到v18
                          │
             最多三轮回退 + 全局门槛审计
                          │
             写入TIFF、读回并再次发布审计
                          ▼
              MEASUREMENT_CANDIDATE v19
```

全流程没有缩放、配准、仿射/非刚性形变、坐标重采样或解析片层重绘。输出数组尺寸必须与原图完全一致，写出类型为`uint16`；代码会在写回后检查尺寸、数据类型和像素往返一致性。

## 5. 方法与模型规格

### 5.1 四区掩膜把噪声预算与结构风险解耦

1. **层纹/夹层完整束**：由结构内部掩膜与左右层纹ROI相交得到，并排除端点和敏感轮廓。该区域使用严格轴向滤波，横向滤波标准差为0，因此不会从相邻层纹或夹层借用样本。
2. **中央实体**：在指定中央ROI内处理，并排除硬锚；该区域没有密集的周期性宽度边界，可使用更强的各向同性估计。
3. **端点外侧雾状区**：取结构包络外侧、远离边界阈值且位于左右层纹束附近的区域，目标是去除层纹外的雾状不清晰残差。
4. **低结构背景**：使用平滑后梯度的第30百分位作为低梯度阈值，并排除侧束、中央实体、硬锚及高保护权重区域。

这些区域使用独立强度，避免v18中“增强边界时顺带改变宽度”的耦合风险。

### 5.2 自适应局部Wiener残差收缩

对每个区域，先使用对称高斯核得到低频估计：

\[
L=G_{\sigma_f}*I,\qquad H=I-L.
\]

再以更大局部窗口估计高频能量：

\[
E=G_{\sigma_l}*(H^2),\qquad
q=\operatorname{clip}\left(\frac{E-\sigma_r^2}{E+\varepsilon},0,1\right).
\]

其中\(\sigma_r=k\hat\sigma_n\)，\(\hat\sigma_n\)来自目标区域的MAD噪声估计。实际去噪增量为：

\[
\Delta I=-(1-q)H.
\]

四区增量按各自强度加权后求和，并受`max(0.85·噪声估计, 2/65535)`的单像素幅度上限约束。使用对称零相位滤波，因此不会引入由因果滤波产生的系统性边缘位移。

当前实现的滤波规格为：

| 区域 | 滤波σ（纵向, 横向） | 局部能量σ | 噪声因子 |
|---|---:|---:|---:|
| 层纹/夹层束 | (1.60, 0.00) | (3.20, 0.00) | 0.60 |
| 中央实体 | (0.75, 0.75) | (2.20, 2.20) | 0.70 |
| 端点外侧雾状区 | (0.85, 0.85) | (2.50, 2.50) | 0.78 |
| 低结构背景 | (0.70, 0.70) | (2.00, 2.00) | 0.75 |

### 5.3 “硬锚”和“测量不变量”采用不同机制

v19明确区分两类保护：

- **端点/敏感轮廓硬锚**：由端点结构场膨胀和端点包络边界共同构成。每个候选处理后，这些坐标都恢复为完全相同的v18像素；发布审计要求16位值的变化数为0。
- **宽度测量不变量**：代码会栅格化部署FWHM与端点检测器实际读取的采样支持域，用于说明和审计测量敏感区域。由于把全部离散FWHM采样带硬冻结会产生可见接缝，宽度不变量不依赖“冻结所有支持域像素”，而由严格轴向滤波、逐行FWHM复测、逐层门槛以及选择性回退共同保证。

除部署时使用的25个宽度采样行外，v19还以3行步长在层纹全长抽样FWHM。单层逐行漂移P95超过0.025 px或最大值超过0.060 px时，该层被判为不安全；全局发布门槛进一步要求逐行漂移P95不超过0.020 px且最大值不超过0.060 px。

### 5.4 候选搜索和选择性回退

候选搜索先独立提高中央、雾状和背景强度，再固定安全组合搜索层纹束轴向强度，避免四维笛卡尔积带来的冗余。当前网格包含从全零基线到更强安全区组合，并对`stack`测试0.02至0.12。

每个候选都执行以下闭环：

1. 应用四区残差增量并恢复硬锚；
2. 先量化为最终将写出的16位像素；
3. 重新测量全部层纹与夹层，并检查额外逐行FWHM；
4. 将宽度、端点、长度或双证据退化的层纹及其邻域恢复为v18；
5. 最多重复三轮，并重新计算噪声、相关性、SSIM和拓扑；
6. 仅在全部门槛通过时参与评分。

评分优先最大化三个低风险区域中最弱的降噪幅度，再加入加权全区降噪收益。这样可防止算法只清理最容易的背景、却保留用户最关心的雾状区。

### 5.5 发布门槛在16位量化闭环内执行

主要门槛包括：

- 端点P95不超过基线允许增量，且层纹长度、夹层长度不退化；
- 层纹宽度误差P95不超过0.35%；
- 夹层宽度误差P95不超过基线加0.02个百分点，且绝对上限为0.40%；
- 层纹与夹层双证据通过数不低于v18；
- 边缘清晰度不低于v18；
- 低频、中频和梯度相关性分别不低于0.99999、0.99990和0.99985；
- 层纹轴向细节相关性中位数/P10不低于0.99997/0.99994；
- 目标ROI内相对v18的SSIM不低于0.99985；
- 选择性回退不超过全部层纹的15%；
- 普通峰计数、层距和约束匹配数量保持拓扑一致；
- 硬锚的16位像素必须逐位一致。

最终TIFF写出后会重新读回并重复结构、局部宽度、拓扑、SSIM和硬锚审计。只有读回结果也通过，才生成发布指标清单。

## 6. 创新点与工程贡献

以下创新是相对于本项目v17/v18流程的工程改进，不代表未经公开基准验证的SOTA主张。

1. **生成质量与测量安全解耦**：v17负责结构条件生成式复原，v18负责有限宽边界清理，v19只管理安全去噪预算和发布审计。每一阶段职责明确，可单独回退和比较。
2. **测量算子感知的保护机制**：保护对象不是笼统的边缘图，而是实际FWHM、端点和层间测量算子的采样支持及其响应；硬锚与响应不变量分别采用合适机制。
3. **各向异性与分区联合设计**：周期性层纹束只允许轴向信息交换，而中央、雾状和背景区域使用独立各向同性强度，兼顾清洁视觉和横向厚度稳定性。
4. **结构级选择性回退**：候选失败时不是放弃整幅图，也不是接受平均指标，而是按层纹和邻近夹层恢复精确v18像素，保护少数临界结构。
5. **量化感知的发布审计**：候选选择和最终验收都在uint16像素上执行，并在TIFF写入/读回后复验，避免浮点阶段通过而量化文件失效。

## 7. 稳健性检查和负面结果

- **无空间几何操作**：没有缩放、配准、透视或非刚性校正，避免插值改变长度和厚度。
- **无解析重绘**：没有用理想片层替换实测层纹，局部缺口、起伏和轴向细节仍来自v17/v18像素。
- **端点位级不变**：硬锚区以uint16逐像素比较，而非只比较平均端点位置。
- **逐层而非只看全局**：全局P95通过仍不足以发布；任一单层局部宽度超限都会触发回退。
- **过强候选可被拒绝**：更大的中央、雾状、背景或stack强度只有在所有几何与细节门槛均通过时才可能被选中。

当前结果只来自一幅目标图像，不能证明对设备、曝光、材料或噪声分布变化具有同等性能。指标描述的是与v18及v16约束的一致性，不是相对于不可获得的无噪声真值的绝对误差。

## 9. 限制与正确使用边界

1. v19没有训练新的生成模型；生成式像素来自上游v17，并由v18与v19保留。
2. `MEASUREMENT_CANDIDATE`表示“通过本项目内部同坐标约束审计”，不表示已经取得计量认证。
3. v16结构载体和导出的逐结构CSV仍应作为测量复核依据；增强图适合检测、显示和辅助测量，不应在未标定条件下单独替代原始数据。
4. 对极低信噪比、层纹粘连、断层或超出当前ROI布局的图像，需要重新验证掩膜、阈值和候选网格。
5. 当前噪声指标为高斯残差代理量，可能同时包含少量真实细节；因此必须与细节相关性和几何门槛联合解释。

## 10. 建议的下一步

- 在更多固定输入哈希上复跑同一容器网格，确认选定参数的跨图稳定性；
- 使用多次同设备重复扫描评估长度/厚度重复性，而不只比较单图结构相似度；
- 引入已知厚度和间距的标准样件，分别标定像素尺寸、PSF/MTF和端点偏差；
- 按曝光水平、材料和层纹位置分层统计回退率，识别是否需要分设备或分噪声档参数；
- 发布时同时保留原图、v16载体、v18输入、v19图像、参数清单和逐层审计CSV，形成可追溯测量链。
