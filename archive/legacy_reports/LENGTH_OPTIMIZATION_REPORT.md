# 层纹端点与长度独立审计报告 v4

## 结论

对经过几何校正和弱结构感知净化的 `QUALITY_boundary_preserved_16bit.tif` 使用 `--sharpen-amount 0` 进行独立审计，共检测100条层纹：99条原始边界参考可靠，1条因原图自身端点不确定度过高而需人工复核。可靠层的端点和长度守卫全部通过。

该审计模式不修改任何输入像素。推荐长度仍来自原始16位图的亚像素拟合，增强图只用于重检测一致性检查。

## 方法

1. 在层纹主体检测中心和周期；
2. 沿弯曲中心逐行跟踪，限制跨层跳变；
3. 沿三条相邻路径提取剖面；
4. 使用一维平滑梯度极值和三点二次拟合定位上下端点；
5. 原始端点作为推荐值，增强端点仅作为漂移诊断；
6. `--sharpen-amount 0` 时进入几何审计模式，不要求增强图与含噪原图的SSIM达到0.99，也不要求其梯度高于原始噪声图；只执行端点、长度和数据质量守卫。

## 复现

```bash
python app/length_optimize.py \
  --source input/source_16bit.tif \
  --denoised results_quality/QUALITY_boundary_preserved_16bit.tif \
  --outdir results_length \
  --sharpen-amount 0
```

输出包括 `layer_lengths.csv`、`length_qa.json` 和端点叠加图。绝对物理长度仍需要像素尺寸、PSF/MTF、标准件和重复扫描标定。
