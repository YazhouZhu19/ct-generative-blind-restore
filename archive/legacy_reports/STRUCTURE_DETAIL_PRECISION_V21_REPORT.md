# v21 原生坐标结构细节精修技术报告

## 摘要

v21 在已通过审计的 v20 图像上继续处理层纹区域，目标是在保留上游生成式盲去噪和后处理效果的同时，降低层纹及夹层附近的残余高频噪声，并把长、宽、左右边界和中心约束落实到最终 `uint16` 像素。

最终验证档位为 `precision_balanced`。算法不执行尺寸变化、配准、坐标形变、重采样或解析层纹重绘，而是在原始 `2200×1600` 网格上进行受限光度修正。正式 TIFF 先写入临时文件，回读后通过 57/57 项发布门控才原子替换 canonical 文件；失败不会覆盖此前的正式结果。

在本图的单图内部审计中：

- 41,327 个逐行 FWHM 样本的绝对漂移 P95/最大值为 `0.003318 / 0.013469 px`；
- 49,713 个左右边界样本全部有效，边位置漂移 P95/最大值为 `0.003269 / 0.019967 px`；
- 中心漂移 P95/最大值为 `0.002184 / 0.009979 px`；
- 层纹/夹层宽度相对误差 P95 为 `0.315009% / 0.208542%`；
- 层纹和夹层方向高频代理相对 v20 分别下降 `0.075599% / 0.004555%`；
- 仅 25,305 个像素发生变化，全部位于固定允许写入掩膜内；中央高亮区、目标 ROI 外、硬锚点均为 0 像素变化；
- 57/57 项写盘后门控与 73/73 项容器内单元测试通过。

这些数字是相对 v20、在当前检测算子和阈值下的单图内部结果，不是物理尺寸标定或计量认证。上游仍含 v17 生成像素，因此输出继续标记为 `MEASUREMENT_CANDIDATE`；非生成的 v16 载体仍是测量回退基线。

## 1. 问题与目标

v20 为避免长度和厚度漂移，把完整层纹/夹层束逐位锁定。这很安全，但层纹内部残余颗粒也无法继续优化。v21 只重新开放有双证据支持、且不改变既有测量响应的低风险层纹像素。

设计目标包括：

1. 保留 v17 生成式增强及 v18–v20 去噪和后处理链；
2. 在原始尺寸和坐标系内进一步抑制层纹/夹层残余噪声；
3. 同时约束左右边、中心、FWHM、端点、长度、逐层宽度和逐夹层宽度；
4. 对量化和文件写回后的真实像素重新审计；
5. 任一结构门控失败时 fail closed。

## 2. 输入、输出与像素链

输入为原始 16 位图、v16 非生成盲去噪载体和 v20 候选。v20 是实际像素基线，已经包含 v17 生成残差及 v18–v20 后处理。

```text
raw source ───────────────┐
v16 non-generated carrier ├─> dual-evidence constraint extraction
v20 enhanced candidate ───┘
             ↓
native-grid photometric proposal
             ↓
uint16 row/layer/gap projection
             ↓
temporary TIFF -> reload -> 57 release gates -> atomic publish
```

最终输出为 `MEASUREMENT_CANDIDATE_v21_structure_detail_precision_16bit.tif`。

本轮还修正了 v17 的审计输入：生成图到候选图的细节审计现在使用真实的 `generated_full`，不再误把 carrier 当作生成图，并额外保存 `GENERATIVE_v17_raw_16bit.tif`。这会提高未来从 v17 重新运行时的审计可信度；本次 v21 以既定 v20 TIFF 为输入，因此该维护修复没有追溯改写当前 v21 像素。

## 3. 方法

### 3.1 原生坐标光度建模

算法沿已测得的弯曲中心线逐侧估计一个共享夹层背景和每根层纹的轴向幅值。候选只改变已有像素强度，不移动坐标，也不构造解析矩形或尖状层纹。代码中没有 resize、registration、warp 或 resampling。

“原生坐标”表示未执行坐标变换，并不表示测得的亚像素边位置数学上恒为零漂移；后者由量化后的测量闭环限制。

### 3.2 双证据轴向自适应收缩

每条轴向信号通过零相位高低频分解得到残余分量。二阶差分 MAD 估计局部噪声尺度；原图与 v16 的相位一致性、幅度接近程度以及当前信号的局部能量共同形成软保留权重。仅在这些启发式证据均较弱时收缩高频。

### 3.3 半高点固定的单调横向候选

横向归一化曲线固定 `0`、`0.5` 和 `1`，在理想归一化轮廓上不移动半高点。它只是候选构造先验，不是最终 FWHM 保证，因为部署算子还会进行 `y±2` 五行平均、横向平滑及局部峰值/背景重估。

### 3.4 材料门控与幅度上限

材料门控在归一化材料响应低于 `0.08` 时关闭，在 `0.30` 以上完全打开，中间平滑过渡；深夹层不会被层纹模型填亮。候选变化还受盲估计噪声尺度控制，本次最大允许归一化变化为 `0.00350947`。

### 3.5 联合逐行结构投影

候选先量化到 `uint16`，再对所有 eligible 层纹行执行联合测量：

- 五行平均 FWHM，容差 `0.018 px`；
- 独立左右边位置，容差 `0.020 px`；
- 双边中心位置，容差 `0.010 px`；
- 两侧边峰强度与符号纯度；
- 边峰是否落在搜索窗边界；
- 无效或基线歧义行是否发生过写入。

违规行只恢复测量算子的最小像素足迹。每轮修复后增加一次只读终态扫描；达到轮数上限仍有违规时，`converged=false`，候选不得发布。

### 3.6 逐层与逐夹层非退化

逐行投影后继续比较 100 条层纹和 98 条夹层的中位宽度、长度、端点和边缘清晰度。夹层退化会同时定位相邻两条层纹。优先恢复 25 行测量足迹，重复失败才恢复完整局部 cell。

本次对 `L12`、`L13`、`L14` 恢复了 10,402 个测量足迹像素，没有完整 cell 回退。最终严格不安全层集合和旧版结构不安全集合均为空。

### 3.7 写入合同与原子发布

允许写入掩膜在运行开始前固定。发布审计要求允许区外、目标 ROI 外、中央高亮区和硬锚点均逐位不变，并禁止新增 0 或 65535 裁剪像素。

正式文件先写入同目录唯一临时 TIFF。只有 dtype、尺寸、逐位回读和全部门控通过后才原子更新 canonical 文件；失败路径删除临时件并保留旧正式件。

## 4. 主要创新点

1. **将形状约束落实到真实测量响应：** 独立限制左右边、中心与 FWHM，可捕获宽度不变但整体平移。
2. **候选先量化、再闭环：** 结构结论基于最终 `uint16` 网格，而不是浮点中间张量。
3. **双证据细节保留：** 原始输入和非生成载体共同影响轴向收缩，避免单一生成先验决定局部纹理。
4. **最小测量足迹恢复：** 只回退测量算子读取的像素，尽可能保留去噪收益。
5. **终态收敛证明：** 修复轮次后额外扫描，阻止未经复核的最后一轮状态发布。
6. **发布级写入合同：** 中央区、目标外和允许区外逐位锁定，并采用原子发布。

这些创新是工程上的可审计保护机制，不代表跨设备、跨曝光或绝对物理尺寸上的计量精度证明。

## 7. 视觉审查

全图和原生像素裁剪未见新增层纹断裂、双边、光晕、中央接缝、端点污染或额外周期网格。变化集中在左右层纹束；中央块完全冻结。左右最外壁是变化最敏感的位置，后续若提高强度应优先检查。

中央块原有颗粒和接合粗糙被保留，这是固定写入合同的预期行为，不是 v21 新增伪影。

## 11. 局限性与结论

- 只有单张图像，没有配对无噪声真值；
- v21 沿用含生成像素的上游结果；
- 当前阈值只在本图与当前测量算子上验证；
- CT 像素值不直接等于物理厚度，仍需像素尺寸、PSF/MTF、曝光和设备标定；
- 视觉改善较克制，优先级是可检测结构的非退化，而不是强锐化观感。

v21 把结构保持从单一宽度扩展为量化后的左右边、中心、FWHM、逐层及逐夹层闭环，并补上终态收敛、固定写入合同和原子发布。对本图，`precision_balanced` 在保留 v20 整体观感的同时获得小幅方向性降噪，且所有当前门控通过。它适合作为后续检测实验的 `MEASUREMENT_CANDIDATE`，正式物理测量仍应以 v16 回退载体和多图标定验证为准。
