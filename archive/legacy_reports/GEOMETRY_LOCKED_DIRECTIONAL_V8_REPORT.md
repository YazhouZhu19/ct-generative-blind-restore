# v8 几何锁定强方向去噪报告

## 结论

v8 重新审查了本仓库公开初版中的 `directional_continuity`。该步骤使用 `sigma=(3,0)` 沿层纹长轴平滑，是原方法中抑制断续颗粒最强的确定性去噪步骤；但初版只用原图横向梯度保护层纹厚度边缘，没有保护上下端点，因此不能单独证明长度不变。

本次没有删除生成式盲去噪、原有增强、v6 边界清洁或 v7 残差去噪。改动是在盲模型完成 Poisson-Gaussian 数据投影之后、任何锐化和对比度增强之前，插入**几何锁定方向投影**。强方向平滑只有在同一个候选同时通过固定原图坐标下的横向厚度、上下端点、整条长度、锐度、对比度及 SSIM 守卫时，才允许进入后续增强链。

## 为什么几何一致性必须放在多个位置

只在最后做一次形状校正不够，因为强去噪一旦把相邻边界混合或把端点抹掉，后处理只能移动已有像素，不能可靠恢复被删除的测量证据。v8 因此在六个位置共同约束：

1. 处理前：从原始 16 位图固定中心、弯曲路径、横向 FWHM 和亚像素端点参考。
2. 模型训练：使用 x/y 边缘、宽度轮廓、端点轮廓和多尺度形状损失。
3. 数据投影：用原图横向层纹中心作坐标锚，限制模型后验改变量。
4. 强去噪入口：新增横向梯度门、纵向梯度门和固定端点保护区；保护发生在平滑候选进入输出之前。
5. 候选选择：逐档检查层数、FWHM、端点、长度、锐度、对比度和 SSIM，拒绝越界强度。
6. 全部后处理之后：长度模块使用固定的处理前 guide 和路径进行独立审计，禁止在增强结果上重新定义测量路径。

其中第 4 点是本次关键修改。它既保留初版强方向去噪的优点，又补上长度方向的几何锁。

## 算法

令 `I0` 为原图、`I` 为已通过盲后验数据投影的结果，先计算仅沿层纹长轴的零相位平滑：

\[
A=G_{(3,0)}(I)
\]

由原图计算横向及纵向安全门，并叠加固定端点保护：

\[
M=\exp[-(g_x/T_x)^2]\,\exp[-(g_y/T_y)^2]\,(1-P_{endpoint})
\]

候选为：

\[
I_\beta=I+\beta M(A-I)
\]

改变量受已选 Poisson-Gaussian 投影上限约束，端点核心保持投影输入像素不变。这里不会回写原图像素，也不会回写生成图像素。程序搜索 `beta={0,0.25,0.40,0.55,0.70}`，以噪声粗糙度降幅最大为目标，但必须满足全部几何和外观守卫。

## 正式 600 轮结果

程序选择 `beta=0.55`。`beta=0.70` 虽然能把盲阶段粗糙度降幅提高到 32.18%，但相对投影输入的 SSIM 只有 0.99418，低于 0.995 门槛，因此被自动拒绝。

| 指标 | v8 正式结果 |
|---|---:|
| 盲投影阶段粗糙度降幅（相对原图） | 26.72% |
| 加入几何锁定方向去噪后的降幅（相对原图） | 31.94% |
| 方向去噪相对投影输入的额外降幅 | 7.12% |
| 方向去噪相对投影输入 SSIM | 0.996309 |
| 方向去噪后端点偏移 P95 | 0.034 px |
| 方向去噪后长度变化 P95 | 0.057 px |
| 最终层纹区高频噪声降幅（相对原图） | 39.47% |
| 最终中央高亮区噪声降幅（相对原图） | 23.96% |
| 最终边缘锐度增益（相对原图） | 5.21% |
| 最终局部对比度增益（相对原图） | 1.94% |
| 最终横向中位 FWHM 最大变化 | 1.28% |

与 v7 最终结果相比，v8 的层纹区高频噪声再降低 1.77%，中央高亮区噪声再降低 5.05%；边缘锐度保留 99.83%，局部对比度保留 99.92%。最终固定路径审计检测 100 条层纹，其中 98 条自动通过、2 条因原始端点证据本身不确定而标记复核；可靠层纹端点偏移 P95 为 0.241 px，长度变化 P95 为 0.403 px。

## 代码和复现

- `app/sota_geometry_blind.py`：`geometry_locked_directional_continuity` 和多强度候选选择。
- `app/run_sota_pipeline.py`：五阶段编排及 v8 汇总指标。
- `tests/test_sota_geometry_blind.py`：端点核心不被强方向去噪改写的单元测试。

完整运行：

```bash
docker compose run --rm ct-sota \
  --source /data/input/source_16bit.tif \
  --generative-prior /data/input/generative_candidate_visual_only.png \
  --outdir /data/results_sota --iterations 600 --device cpu
```

正式输出仍使用 v7 残差模块的兼容文件名 `04_residual_denoise/QUALITY_v7_residual_denoised_16bit.tif`；它在 v8 流程中已经接收新增的几何锁定强方向去噪结果。测量前应检查 `01_sota_blind/sota_run_manifest.json` 中的 `directional_projection_selection` 和 `05_length_audit/length_qa.json`。

## 限制

这些数字是单张图像的内部一致性验证，不是无噪声真值误差，也不是计量认证。物理长度仍需像素尺寸标定、可追溯标准件、PSF/MTF 表征以及重复扫描验证。
