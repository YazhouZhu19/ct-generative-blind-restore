# v12 边缘清晰与原图双证据约束报告

## 目标

v12 在 v11“去噪引导测量—原图生成—解析硬投影”的基础上解决两个问题：进一步提高层纹左右边界和端点清晰度；把最终图与原始输入图的比较从层纹端点扩展到每条层纹及每个夹层的长度和宽度。

## 方法改进

### 1. 清晰边缘解析投影

层纹横截面继续使用有限宽双 logistic 片层，但横向边缘过渡由 `0.38 px` 收紧到 `0.24 px`，纵向端点过渡由 `0.55 px` 收紧到 `0.40 px`。三轮FWHM闭环校准随后补偿亚像素光栅化与低频背景的影响，因此锐化不改变目标厚度。

边缘清晰度使用每条层纹较弱一侧的归一化横向斜率：

\[
C_i=\operatorname{median}_y\frac{\min(s_{L,i}(y),s_{R,i}(y))}{I_{peak,i}(y)-I_{base,i}(y)}
\]

该指标越大表示边缘越陡。所有图像用相同的纵向采样、路径和 `sigma=0.65 px` 剖面平滑测量。

### 2. 原图层纹完整比对

每条层纹的CSV同时记录：

- 去噪引导图、原图和最终图的顶部、底部及长度；
- 三幅图的横向FWHM；
- 原图、引导图和最终图的边缘清晰度；
- 最终图相对两套基准的误差；
- 原图宽度/长度非退化判定及最终双证据判定。

原图有噪声，因此不强迫最终图逐像素追随原图测量。使用非退化门限：最终图到原图的误差不得大于“引导图到原图的既有差异 + 原图自身测量容差”。这样既增加原图约束，又不会把原图噪声重新写入清晰边界。

### 3. 原图夹层完整比对

对98个相邻夹层，分别计算引导图、原图和最终图的逐行间隙宽度及共同纵向长度。夹层宽度为：

\[
g_i(y)=p_{i+1}(y)-p_i(y)-\frac{w_i+w_{i+1}}{2}
\]

输出独立的 `interlayer_dual_evidence_comparison.csv`，不再只审计层纹本身。

### 4. 双证据验收

最终结果必须同时满足：

1. 对去噪引导图的层纹端点、长度和宽度误差门限；
2. 对原图的层纹长宽非退化门限；
3. 对去噪引导图的夹层长宽误差门限；
4. 对原图的夹层长宽非退化门限；
5. 输出边缘清晰度不低于去噪引导图。

## 本图实验结果

| 指标 | 结果 |
|---|---:|
| 约束匹配层纹 | 49左 + 51右 = 100 |
| 约束匹配夹层 | 98 |
| 层纹双证据通过 | 100 / 100 |
| 夹层双证据通过 | 98 / 98 |
| 引导坐标端点误差P95 | 0.0374 px |
| 引导坐标长度误差P95 | 0.0443 px |
| 原图端点差异P95 | 0.1451 px |
| 原图长度差异P95 | 0.1705 px |
| 引导层纹宽度相对误差P95 | 0.1699% |
| 引导夹层宽度相对误差P95 | 0.1260% |
| 原图夹层宽度相对差异P95 | 7.31% |
| 原图夹层长度绝对差异P95 | 0.2377 px |
| 原图边缘清晰度 | 0.3061 |
| v11边缘清晰度 | 0.3599 |
| v12边缘清晰度 | **0.3883** |

v12相对v11的边缘清晰度提高约7.9%，相对原图提高约26.9%。目标层纹中位宽度为 `4.251057 px`，输出为 `4.251003 px`。

原图层纹宽度差异P95仍为17.77%，主要来自低信噪原图的FWHM波动，因此该值作为原图证据范围而不是直接的生成目标；100条层纹仍全部通过“相对原图不退化”判定。

## 输出

- `GENERATIVE_shape_hard_projected_16bit.tif`：2200×1600、16位最终视觉图。
- `lamella_dual_evidence_comparison.csv`：100条层纹三方长宽、清晰度和判定。
- `interlayer_dual_evidence_comparison.csv`：98个夹层三方长宽和判定。
- `GENERATIVE_raw_input_comparison_overlay.png`：原图端点与最终端点叠加检查。
- `hard_shape_projection_metrics.json`：全部汇总指标与五项门限。

## 使用边界

双证据约束证明最终图没有比去噪引导测量更偏离原始输入，但不等同于计量认证。生成纹理和低频外观仍是视觉成分；正式厚度、长度或缺陷验收仍需使用非生成式16位链路、像素尺寸标定及系统PSF/MTF验证。
